# Gatekeeper – Custom API Management System

## Overview
Gatekeeper is a backend application built with Java and Spring Boot that helps developers and organizations manage APIs through a centralized system. It supports organization management, API-related operations, and reliable data handling using REST APIs and MySQL.

## Features
- Centralized API management
- Organization management and active-status validation
- RESTful API development
- MySQL database integration
- Exception handling and request validation
- Structured backend architecture

## Tech Stack
- **Language:** Java
- **Framework:** Spring Boot
- **Database:** MySQL
- **API:** REST APIs
- **Build Tool:** Maven
- **IDE:** IntelliJ IDEA
- **Database Tool:** DBeaver

## Getting Started

### Prerequisites
- Java 21
- Maven
- MySQL
- IntelliJ IDEA or another Java IDE

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/snehalfulari6-alt/gatekeeper.git
   ```
2. Open the project in IntelliJ IDEA.
3. Create the required MySQL database and configure your database connection.
4. Set database credentials using environment variables or local configuration.
5. Run the Spring Boot application.

### Running the Application
Start the application from IntelliJ IDEA by running the main Spring Boot application class.

The application runs on port `8081` by default, if the configured port has not been changed.
